## ⚡ Get Started in 3 Steps

### 1️⃣ Install
```bash
pnpm install
```

### 2️⃣ Configure
```bash
cp .env.example .env.local
# Add API key from https://platform.deepseek.com/
```

### 3️⃣ Run
```bash
pnpm dev
# Open http://localhost:3000
```

✅ **That's it! Now you can chat with AI**

## 🆘 Help

### Common Issues
| Issue | Fix |
|-------|-----|
| App won't start | Check Node 18+, run `pnpm install` |
| No API response | Verify DeepSeek API key is valid |
| Voice not working | Check browser microphone permission |
| Build fails | Clear cache: `rm -rf .next node_modules` |
