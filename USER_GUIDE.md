# EIH AI Assistant - User Guide

Welcome to the Ethiopian Investment Holding AI Assistant powered by DeepSeek!

## Getting Started

### 1. Sign In

- Enter your email address (or use demo mode for testing)
- Click "Sign in with Microsoft" or "Continue as Demo User"
- You'll be taken to the main chat interface

### 2. Your First Chat

1. Click "New Chat" in the left sidebar
2. Type your question or request
3. Press Enter or click the Send button
4. The AI will respond with a detailed answer

## Features Guide

### Chat Interface

The main area where you interact with the AI:

- **Message History**: All messages in the current conversation appear here
- **User Messages**: Shown in cards with your avatar
- **AI Responses**: Displayed with the AI avatar and gold accent
- **Copy Button**: Click to copy any message to clipboard

### Sidebar

Left panel with navigation and quick access:

- **EIH AI Header**: Company branding and status
- **New Chat Button**: Start a new conversation
- **Chat History**: List of previous conversations
- **Quick Start**: Common use cases for quick access

### Document Upload

Add files to enhance your conversation:

1. Click in the upload area or drag files
2. Supported formats:
   - 📄 Documents: PDF, Word (.docx), Excel (.xlsx)
   - 📝 Text: Plain text (.txt), CSV
   - 🖼️ Images: PNG, JPG
3. Files are attached to your next message
4. Maximum file size: 10MB per file

### Voice Input

Use voice to dictate messages:

1. Click the microphone icon
2. Start speaking (you'll see "Listening..." status)
3. Your speech is automatically transcribed
4. The text appears in the message box
5. Click Send to submit

**Note**: Voice input requires microphone permission. Works best in Chrome or Edge.

### Voice Output

Have responses read aloud:

1. Click the speaker icon after receiving a response
2. The AI's message will be spoken aloud
3. Click again to stop

**Note**: Text-to-speech quality depends on your browser.

Click "New Chat" button in the sidebar to start a fresh conversation.

- Chat titles are auto-generated from your first message
- You can manually update titles by editing the chat

## Tips for Best Results

### Writing Good Prompts

**Be Specific**: Instead of "Tell me about investments"
→ "What are the top 5 investment opportunities in tech startups?"

**Provide Context**: Include relevant background information
→ "We're a retail company looking to expand to e-commerce. What are the main challenges?"

**Ask Follow-ups**: Refine responses with additional questions
→ First: "What is market segmentation?"
→ Follow-up: "How do we use this for retail?"

### Using Documents

1. **Summarize**: "Summarize the key points from this document"
2. **Extract**: "Extract all financial figures"
3. **Analyze**: "What risks are mentioned?"
4. **Compare**: Upload multiple documents and ask differences

### Voice Tips

1. Speak clearly and at a normal pace
2. Use the microphone in a quiet environment
3. Allow 2-3 seconds after finishing before releasing the button
4. Try again if recognition is inaccurate

## Limitations & Best Practices

### What Works Well
- General information and research
- Writing and content generation
- Analysis and summarization
- Problem-solving discussions
- Code examples (for developers)

### What Doesn't Work
- Real-time information (prices, weather, current news)
- Personal data processing
- Specialized professional advice (legal, medical)
- Accessing external websites or databases

### Privacy & Security
- Your conversations are stored in-session
- For production use, ensure data encryption
- Don't share sensitive personal information
- Clear your chat history when finished

## Troubleshooting

### AI Not Responding

1. Check internet connection
2. Verify DeepSeek API key is configured
3. Wait a moment and try again
4. Try a shorter message

### Voice Not Working

1. Check microphone is enabled
2. Test microphone in browser settings
3. Try Chrome or Edge browser
4. Disable browser extensions if issues persist

### Files Won't Upload

1. Check file size (max 10MB)
2. Verify file format is supported
3. Try a different file
4. Clear browser cache

### Chat Disappeared

- Sessions are in-memory (lost on refresh)
- For persistent storage, use production database
- Save important chats before closing

### Slow Responses

1. Check internet speed
2. DeepSeek API might be busy
3. Try a shorter message
4. Wait a few moments between requests
